Automated Weather Monitoring in Microsoft Fabric

Overview
A fully managed, end-to-end streaming solution on Microsoft Fabric that ingests live Delhi weather telemetry through Eventstreams into an Eventhouse with sub-second latency, replacing batch polling, and raises automated alerts when temperatures breach high or low thresholds.

Tech Stack
- Platform: Microsoft Fabric (SaaS)
- Ingestion & Processing: Eventstreams
- Storage: Eventhouse (KQL Database)
- Alerting: Fabric Activator (two activators: high and low temperature)
- Visualization: Real-Time Dashboard

The Challenge
Traditional streaming architectures often require stitching together complex, disparate services (e.g., Kafka, Spark Streaming, and separate alerting tools), leading to high maintenance overhead. The objective was to demonstrate a Unified Analytics approach, building a robust real-time pipeline entirely within a single SaaS environment without managing underlying infrastructure.

The Solution
I architected a seamless "Ingest-to-Insight" flow within a single Fabric workspace:
- No-Code Ingestion: Configured a native Weather Connector to continuously pull live atmospheric data for Delhi.
- Stream Routing: Utilized Eventstreams to capture, transform, and route high-velocity data into storage without writing complex glue code, replacing batch polling.
- Real-Time Storage: Provisioned an Eventhouse to store the streaming data, enabling fast querying using KQL (Kusto Query Language) with sub-second latency.
- Automated Alerting: Configured two Fabric Activators, one for high-temperature and one for low-temperature thresholds, replacing manual monitoring.
- Live Dashboard: Built a Real-Time Dashboard showing live readings, trends and alert history.

Key Highlights
- Results: Sub-second latency replacing batch polling; automated high/low temperature alerts replacing manual monitoring.
- Event-Driven Architecture: Moved beyond static reporting to active intelligence with automated triggers and alerts.
- Live Visualization: A Real-Time Dashboard with live readings, trends and alert history gives continuous situational awareness.
- Unified Platform: Ingestion, storage, alerting and visualization all run inside a single Microsoft Fabric workspace.

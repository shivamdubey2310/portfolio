Near Real-Time CDC Lakehouse Pipeline

Results
Downstream queries see near-current data instead of day-old snapshots.
- 24h → sub-10 min | Data latency
- 1M+ | Records processed

Overview

A metadata-driven, near real-time Change Data Capture (CDC) Lakehouse pipeline built on Microsoft Azure that incrementally ingests OLTP changes (1M+ records) into a Delta Lake using a Medallion Architecture (Bronze → Silver → Gold).

The system reduces data latency from 24 hours (daily batch loads) to under 10 minutes, so downstream queries see near-current data instead of day-old snapshots, without the operational overhead of full streaming infrastructure.

Tech Stack

- Source Database: Azure SQL Database (Change Tracking enabled)
- Orchestration: Azure Data Factory (Tumbling Window Triggers)
- Storage: Azure Data Lake Storage Gen2 (Parquet – Bronze layer)
- Processing Engine: Azure Databricks (PySpark)
- Table Format: Delta Lake (ACID transactions & MERGE)
- Analytics Layer: Azure Synapse Analytics (Serverless SQL)
- Languages: Python, SQL, PySpark

The Challenge

Traditional batch ETL pipelines refresh data once per day, creating stale dashboards and delayed business decisions.

Full streaming solutions (Event Hub/Kafka) solve latency but introduce:

- Higher infrastructure cost
- Operational complexity
- Increased maintenance overhead

The challenge was to design a cost-efficient, enterprise-friendly alternative that provides near real-time freshness while remaining simple to operate and resilient to failures.

The Solution

I engineered a stateful, idempotent micro-batch architecture that balances freshness, cost, and reliability:

- Metadata-Driven CDC Extraction: Used SQL Change Tracking (CHANGETABLE) to extract only the rows changed since the last successful run, tracked in a cdc_metadata table that stores the last processed version.

- Idempotent Retry Logic: Metadata is updated only after successful downstream processing, so failed runs can be safely retried without data duplication.

- Medallion Lakehouse Architecture:

  - Bronze: Raw CDC data stored in Parquet
  - Silver: PySpark deduplication followed by Delta MERGE upserts (ACID compliant)
  - Gold: Aggregated business-ready datasets (e.g., sales summary by status)

- Micro-Batch Orchestration: Configured ADF Tumbling Window Triggers to run the pipeline in sub-10-minute intervals, delivering near real-time freshness without streaming infrastructure.

- Zero-Compute Querying: Gold Delta tables are queried directly through Synapse Serverless, with only incremental changes processed upstream.

Key Highlights

- Enterprise-Grade Design: Implements Medallion Architecture and ACID Delta MERGE upserts, patterns widely used in production lakehouse environments.

- Idempotent & Retry-Safe: Metadata-driven version control guarantees consistent re-runs and fault tolerance.

- Cost-Optimized Architecture: Avoids streaming infrastructure; processes only incremental changes; uses auto-terminating Databricks clusters.

- Late Data Handling: Watermark logic ensures late-arriving records are safely processed.

- Zero-Compute Analytics: Gold tables are queryable via Synapse Serverless (OPENROWSET) with no dedicated compute, because only incremental changes are processed.
